## Layout

| Path | Description |
|---|---|
| `app/` | Laravel application code (console commands, jobs, providers, logging) |
| `bootstrap/` | Application bootstrap and autoloading |
| `config/` | Framework and application configuration files |
| `database/` | Migrations, seeds and factories |
| `framework/` | ProcessMaker core framework (workflow engine, API, permissions) |
| `gulliver/` | Gulliver UI framework — JS widgets, CSS, and PHP components |
| `rbac/` | Role-based access control module |
| `resources/` | Views, language files and front-end assets |
| `thirdparty/` | Vendored third-party integrations |
| `vendor/` | Composer dependencies (shipped with the community release) |
| `workflow/` | Workflow resources and process assets |

Key top-level files:

- `processmaker` / `processmaker.bat` — cross-platform installer scripts
- `pmos.conf.example` — example configuration for the installer
- `composer.json` / `composer.lock` — PHP dependency definitions
- `package.json` / `package-lock.json` — front-end (npm) dependency definitions
- `gulpfile.js`, `webpack.config.js`, `webpack.mix.js` — asset build pipelines
- `INSTALL.txt` — full installation instructions
- `patch` — upstream patch helper script

## Installation

See [`INSTALL.txt`](INSTALL.txt) for the complete step-by-step guide. In short:

```bash
# 1. Configure the installation
cp pmos.conf.example pmos.conf
$EDITOR pmos.conf

# 2. Run the installer (creates public/, storage/ and the database schema)
sudo ./processmaker
```

Requirements include PHP, MySQL 5.1.6+, Apache 2.2.3+ with `mod_rewrite`, `mod_vhost_alias`,
`mod_deflate` and `mod_expires`.

## Notes

- `vendor/` is committed on purpose: the community release is distributed as a ready-to-install
  package that ships its Composer dependencies.
- `public/` and `storage/` are **not** part of the release; they are generated by the installer.
